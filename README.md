# gen-NetTools

gen-NetTools 是面向网络工程师的 Windows x64 桌面工具。0.1.2 提供离线 NSIS 安装包。

应用支持华为设备日志解析、配置文本差异、IPv4/IPv6 路由快照变化比对、日志字段库导入更新，以及华为 CLI 自动化下发。模型接口可选配置为 OpenAI 格式兼容服务。

字段库、模型设置和分析历史由 Windows 用户共享。日志、配置和路由快照原文不作为历史输入保存。每个分析模块保留最近三次成功结果。
